# REGRA INVIOLÁVEL — PROIBIÇÃO ABSOLUTA DE DADOS FICTÍCIOS (ZERO MOCKS)

É estritamente proibido criar, inserir ou exibir dados fictícios, mocks, seeds inventados, números estimados ou exemplos falsos em qualquer parte do site, banco de dados ou API — nem mesmo para fins de teste, layout ou placeholder. Se um dado real não estiver disponível na fonte oficial ou no banco, exiba um estado vazio honesto ("Dados ainda não sincronizados com a fonte oficial"), mas JAMAIS invente um único número, nome, data ou texto.
