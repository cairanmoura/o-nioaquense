Widget lateral com os últimos sorteios (Mega-Sena, Quina, Lotofácil), com barra verde e dezenas em chips.

A barra segue o Plantão (`nq-sec-h`, `rotulo-secao`). Cada loteria é uma linha (`nq-lot`) com o nome em `verde-institucional` à esquerda e a rodada e a data em `meta` à direita ("#3072 · 20/10"). As dezenas são chips `nq-dz` com estilo `dezena`: fundo `verde-institucional`, texto `on-verde`, números tabulares, com dois dígitos ("02", "09") e quebra de linha livre (a Lotofácil usa duas fileiras).

Quem consome fornece nome, número do concurso, data e dezenas já formatadas.
